#  PetSphere — Pet Adoption & Care

##  Project Overview
PetSphere is a Streamlit application designed to bring pet adoption and pet care services together in one place. Users can explore pets, manage favorites, submit adoption requests, track pet health, book services, and estimate pet care expenses.

##  Features

- **Home:** Overview of available pets and pet care services.
- **Explore Pets:** Filter pets by type, gender, and location.
- **Favorites:** Save favorite pets and manage your list.
- **Pet Adoption:** Submit adoption requests and view adoption summaries.
- **Pet Services:** Explore services, schedule appointments, and view booking details.
- **Health Tracker:** View vaccination information and recommended health checks.
- **Pet Cost Planner:** Calculate estimated monthly and yearly pet care expenses.
- **My Pet Dashboard:** View pet information and recent service history.

##  Technologies Used
- Python
- Streamlit

##  Installation and Setup

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project folder:

   `cd YOUR_REPOSITORY_FOLDER`

3. Install the dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

##  Disclaimer
This is a demonstration application. Pet information, prices, and services use sample data. Adoption requests and service bookings are not connected to a real backend or payment system.
